# CatProbe

[Open CatProbe](https://khuochongtran123.github.io/catprobe-web/)

Drag in a level JSON, enter the maximum number of moves and analyze.

The .NET solver runs inside a browser Web Worker using WebAssembly. Level files stay on your device. No server, installed .NET runtime, or account is required to analyze levels. The default search budget is 60 seconds. Results are the best replay-verified plan found within the budget, not a proof of optimality.

This repository contains prebuilt static website assets, not the generator source.
